# BGN-Hackathon Submission - Agent Apollo
This is a repo for our submission to the Google BGN Hackathon, Team 4.

Our project is Agent Apollo, a Gemini enabled customer sentiment analysis tool built with Python and React. It provides actionable
insights to businesses based on customer data scraped from social media sites. It uses Google Cloud’s Natural Language Processing API and the GCP Gemini API. We won third place!
